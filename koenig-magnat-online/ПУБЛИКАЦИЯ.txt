КАК ЗАПУСТИТЬ ИГРУ В ИНТЕРНЕТЕ (через сервер, без прямого соединения браузеров)

Игра теперь работает через свой небольшой сервер (server.js). Все игроки подключаются к нему
обычным защищённым соединением, как к любому сайту, поэтому NAT и блокировки звонков не мешают.
GitHub Pages сервер запустить не умеет, поэтому сервер живёт на Render (бесплатно).

1. GitHub: загрузи СОДЕРЖИМОЕ этой папки в корень репозитория (Add file → Upload files → Commit changes).
   Нужны все файлы, включая server.js и package.json. Папку node_modules загружать не надо.
2. Render: зайди на render.com, войди через GitHub.
3. New → Web Service → выбери репозиторий с игрой.
4. Настройки: Runtime — Node; Build Command — npm install; Start Command — npm start; тариф — Free.
5. Create Web Service. Через пару минут появится адрес вида https://имя.onrender.com — это и есть ссылка на игру.
6. Создатель открывает этот адрес, создаёт комнату и кидает ссылку друзьям. Вкладку создателя держать открытой.

Бесплатный сервер засыпает, если 15 минут никто не играет, и просыпается примерно за минуту.
Поэтому первый вход после перерыва может занять до минуты — это нормально.

Проверка: адрес/diagnostics.html покажет, отвечает ли сервер и работает ли соединение для комнат.

Если хочешь, чтобы игра открывалась и по ссылке GitHub Pages: впиши адрес Render в index.html,
в строку <meta name="km-server" content="https://имя.onrender.com">.
