# Кёниг Магнат

Онлайн-игра для компании: скупаем Калининград. До 6 игроков, работает с телефона и компьютера.

## Как выложить на GitHub Pages
1. Загрузи в публичный репозиторий все файлы и папку `fonts` (Add file → Upload files, перетащить всё сразу).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту игра откроется по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/` (плюс имя папки, если файлы лежат в папке).

## Как играть вместе
Один нажимает «Создать комнату» и кидает друзьям ссылку или код. Создатель должен держать вкладку открытой: партия и таймер живут у него в браузере.

## Что где менять
- `data.js` — клетки, цены, фишки и тексты карточек.
- `art.js` — рисунки клеток.
- `engine.js` — правила.
- `app.js`, `style.css`, `index.html` — интерфейс, звук, анимации.
